     1→# Attitude360 HRMS - Work Log
     2→
     3→## Current Project Status (Updated: Round 10 - 2025-08-21)
     4→
     5→Attitude360 is a comprehensive HRMS (Human Resource Management System) application built with Next.js 16, TypeScript, Prisma ORM (SQLite), Tailwind CSS 4, shadcn/ui, TanStack Query, Zustand, Framer Motion, NextAuth.js v4, and next-themes. The application is a single-page app (SPA) with client-side navigation via Zustand store and lazy-loaded modules, with **full authentication and role-based access control**.
     6→
     7→### Architecture
     8→- **Framework**: Next.js 16 App Router (single page at /) with React.lazy for code splitting
     9→- **Authentication**: NextAuth.js v4 with Credentials provider, JWT strategy, bcrypt password hashing
    10→- **Authorization**: 4-tier role system (FOUNDER, COFOUNDER, HR, EMPLOYEE) with permission-based navigation
    11→- **Database**: SQLite via Prisma ORM (10 models, employees have password + role fields)
    12→- **State Management**: Zustand for navigation/UI state, TanStack Query for server state
    13→- **UI Components**: shadcn/ui (New York style) with Lucide icons
    14→- **Charts**: Recharts (area, bar, pie/donut charts)
    15→- **Animations**: Framer Motion for page transitions, staggered effects, micro-interactions
    16→- **Theming**: Dark mode via next-themes with class strategy, CSS variable system
    17→- **Styling**: Tailwind CSS 4 with gradient accents, glassmorphism, consistent design language
    18→

    35→### Key Features
    36→- **Global Search** (header bar) - Real-time cross-entity search across candidates, clients, jobs, employees with debounced API, grouped results, keyboard navigation (arrows/escape/enter), entity-colored group headers, mobile fallback to command palette
    37→- **Command Palette** (Cmd+K) - 13 navigation items + 4 quick actions with keyboard shortcuts

    40→- **Bulk Actions** - Multi-select candidates with checkbox, mass status update, mass delete

    46→- **Enhanced Dialogs** - All 7 add/edit dialogs have gradient top bar + icon header (EnhancedDialogHeader component)
    47→- **Back-to-Top Button** - Floating button appears after 300px scroll, framer-motion animation, smooth scroll to top
